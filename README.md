# Прилив (рабочее название)

Браузерная 2D-аркада: моряк на плоту ловит сетью плывущие предметы, растит плот и автоматику, отбивается от морских врагов и проходит кампанию из четырёх локаций по карте моря; весь опыт идёт в общий рейтинг. Жанр — по мотивам Sea Catcher (Poki); мир, модели, интерфейс, тексты и баланс свои.

Стек: TypeScript, PixiJS 8, Vite, Vitest, Playwright. Площадки первого выпуска: Яндекс Игры (через песочницу Playgama) и CrazyGames — одна сборка, связь с площадками через Playgama Bridge.

## Команды
- `npm install` — один раз после клонирования (нужны Node.js 22.12+ и npm 11+), затем `npx playwright install chromium`.
- `npm run dev` — игра в браузере с перезагрузкой при правках.
- `npm run check` — проверка таблиц, тесты, сборка с отчётом о размере и смоук в двух раскладках.
- `npm run publish` — опубликовать сборку для телефона: https://nikitayaponov12345-stack.github.io/tide-play/
