# Прилив (рабочее название)

Браузерная 2D-игра: база в потоке предметов, ловля сетью, уровни и карточки улучшений. Жанр — по мотивам Sea Catcher (Poki); мир, модели, интерфейс, тексты и баланс свои.

Стек: TypeScript, PixiJS 8, Vite, Vitest, Playwright. Площадки: Яндекс Игры, CrazyGames, Playgama (одна сборка), Poki — отдельно.

## Команды
- `npm install` — один раз после клонирования (нужны Node.js 22.12+ и npm 11+), затем `npx playwright install chromium`.
- `npm run dev` — игра в браузере с перезагрузкой при правках.
- `npm run check` — тесты, сборка с отчётом о размере и смоук в двух раскладках.
