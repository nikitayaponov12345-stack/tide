# M0-09 — бот «человек» и замер темпа (`npm run sim`)

**Цель.** Ворота M0 (ROADMAP): у бота «человек» 2-й уровень — до 10 с игрового времени. Бот играет на ядре `Game` без браузера теми же командами, что палец (CLAUDE.md, правило 9). `npm run sim` гоняет его на многих сидах, печатает отчёт темпа и проверяет ворота.

Вместе с ботом — решение Никиты 09.10: на старте у самого плота 6 предметов вместо 3 (`seed_near_raft`). Прототип бота показал:
- при трёх предметах 2-й уровень — медиана 10,9 с по 200 играм, в 115 играх дольше 10 с;
- при шести — 7,7 с, дольше 10 с — 52 игры из 200.

Почему так: 3–5 предметов в круге броска бот ловит за 4–6 с, потом круг пустеет, а новые доплывают до него по 5–8 с.

**Что изменится в игре.**
- На старте у плота 6 предметов (было 3): первые броски ловят больше, 2-й уровень приходит раньше.
- Новый счётчик `stats.xpByRole` — опыт вернувшегося улова по ролям. Виден в `__game.state().stats`.
- Версия — 0.0.7: в `main.ts`, `package.json` и в двух полях `version` в `package-lock.json`.

Бот и отчёт в сборку игры не входят: `src/sim/` из `main.ts` не импортируется.

## 3. Бот — `src/sim/bot.ts` (новый)

Класс `HumanBot(game, data, rng, params = HUMAN)`. У бота свой `Rng`: `new Rng(seed + 3)` (мир — `seed`, колода — `seed + 1`, враги — `seed + 2`).

Параметры `HUMAN` взяты из GDD «Темп и баланс» и TESTPLAN §5; задержки и промахи — как у бота «человек» из разбора оригинала. Это модель игрока, а не баланс игры, поэтому параметры живут в коде бота, а не в таблицах.

| Параметр | Значение | Что это |
|---|---|---|
| `reactionMs` | [250, 700) | От «сеть у моряка» до броска, мс игрового времени |
| `aimSigma` | 14 | Промах броска сети: нормальное отклонение по каждой оси, σ в точках |
| `pullDelayMs` | [150, 900) | От падения сети до удержания, мс; бросается заново при каждом броске |
| `windowMs` | [2500, 3000) | Окно выбора, мс по часам |
| `buildMs` | [1200, 2500) | Стройка клетки, мс по часам |
| `crabNoticeMs` | [500, 1000) | Заметить краба в круге дальности, мс игрового времени |
| `spearSigma` | 12 | Промах копья, σ по оси |
| `retryMs` | 80 | Цели нет — следующая попытка через столько мс |

- Интервал `[a, b)` — `rng.range(a, b)`.
- Нормальное отклонение `gauss()` — Бокс — Мюллер, два броска: `u = 1 − rng.next()`, `v = rng.next()`, результат `√(−2 ln u) · cos(2πv)`.

**`update()`** — перед каждым шагом игры, когда нет паузы. «Сейчас» — `game.stats.gameMs`, сравнение времени — `now + TIME_EPS >= t`. Шаги по порядку:
1. **Краб.** Ближайший к моряку враг из `game.enemies.list` на расстоянии не больше `spear.range`; копья нет (`!spearOwned`) — краба нет.
   - Краба нет → `crabAt = null`.
   - Краб есть, а `crabAt === null` → `crabAt = now + range(crabNoticeMs)`.
   - Краб есть и время `crabAt` пришло:
     - слот не копьё → отпустить удержание, если бот держит, и `setWeapon('spear')`;
     - `spear.state === 'ready'` → `throwTo(x краба + gauss · spearSigma, y краба + gauss · spearSigma)`: сначала промах по x, потом по y.

     На этом `update` заканчивается.
2. Слот не сеть → `setWeapon('net')`.
3. **Сеть `ready`:**
   - бот держит удержание → `setPull(false)`;
   - `pullAt = null`;
   - `throwAt === null` → `throwAt = now + range(reactionMs)`;
   - время `throwAt` пришло → цель (ниже). Цель есть и `throwTo` прошёл → `throwAt = null`, `pullDelay = range(pullDelayMs)`. Иначе → `throwAt = now + retryMs`.
4. **Сеть `lying`, бот не держит:** `pullAt === null` → `pullAt = now + pullDelay`; время пришло → `setPull(true)`, бот держит.
5. `flying` и `pulling` — ничего.

**Цель сети** — как у бота разбора.
- Кандидаты — предметы `world.items` в порядке массива:
  - расстояние от моряка — не больше `range + 10` (`range` — `net.netParams.range`);
  - не ближе 8 точек к краю поля: `|x| ≤ halfW − 8` и `|y| ≤ halfH − 8`.
- Ценность кандидата — сумма `xp` всех предметов ближе 45 точек к нему, вместе с ним самим.
- Счёт = ценность − расстояние / 250 + `range(0, 1.5)`. Шум бросается для каждого кандидата, по порядку. Берётся наибольший счёт; при равенстве — первый.
- Упреждение — `t = 0,6 × расстояние / v̄` секунд, где `v̄ = net_flight_speed × (1 + net_flight_end_mult) / 2`.
- Точка броска = предмет + `world.velocityOf(предмет) × t` + промах (`gauss · aimSigma` сначала по x, потом по y). Затем точку зажать в поле `[−halfW, halfW] × [−halfH, halfH]`.
- Кандидатов нет → цели нет, промах не бросается.

**`pause()`** — на окне или стройке, возвращает `{ ms, card }`. Сначала — отпустить удержание, `throwAt = null`, `pullAt = null`.
- **Окно.** `ms = range(windowMs)`.
  - Карточка — первая доступная по порядку `CARD_ORDER`: `raft`, `throw_farther`, `net_bigger`, `net_wider`, `pull_stronger`, `spear_stronger`. Если таких нет — первая доступная.
  - `takeCard` не прошёл → ошибка. `card` — id взятой карточки.
- **Стройка.** `ms = range(buildMs)`.
  - Клетка — из `raft.candidates()` с наименьшим `gx² + gy² + (gy > 0 ? 0,3 : 0) + (gx < 0 ? 0,2 : 0)`: плотно к центру, чуть к притоку (течение Лагуны приходит справа сверху). При равенстве — первая.
  - `placeCell` не прошёл → ошибка. `card = null`.
- В M0 бот моряком не ходит — как боты разбора.

## 4. Прогон — `src/sim/run.ts` (новый)

`runSim(data, seed, opts = DEFAULT_SIM): SimResult`, где `DEFAULT_SIM = { maxGameMs: 40 мин, untilLevel: 40, bot: HUMAN }`.
- Игра — `new Game(data, { halfW: 640, halfH: 360, speedMult: 1, locationId: 'lagoon', seed })`: горизонталь, как у «руки». Бот — `new HumanBot(game, data, new Rng(seed + 3), opts.bot)`.
- Цикл:
  - пауза → `bot.pause()`, часы += `ms`;
  - иначе: уровень ≥ `untilLevel` или `gameMs ≥ maxGameMs` → конец;
  - `bot.update()`, `game.step(STEP_MS)`, часы += `STEP_MS`;
  - уровни 2, 10, 20, 40 — первое достижение: игровое время (`stats.gameMs`) и часы.

  Число шагов ограничено: больше предела → ошибка.
- Реклама: точка `window_close` из `ads.csv` ставится на закрытом окне, если по часам с начала прошло не меньше `first_after_s`, а с прошлой точки — не меньше `cooldown_s`. Рекламы в M0 нет — бот только считает точки.
- `SimResult`:
  - `seed`, `level`, `gameMs`, `wallMs`;
  - `levelGameMs` и `levelWallMs` — уровень → мс или `null`;
  - `throws`, `itemsCaught`, `emptyThrows`, `spearThrows`, `spearHits`, `enemiesKilled`, `enemiesEscaped`, `lootDropped`;
  - `cells`, `windows`, `cards` (id → сколько раз взята);
  - `xp: { flow, loot, chest, boost }`: `flow` — сумма ролей `FLOW_ROLES`, `loot` — `loot`, `chest` — `boss_chest`, `boost` — 0 до M1;
  - `adPoints`.

## 6. Тесты — `tests/unit/bot.test.ts` (новый)

В каждом цикле — предел числа шагов.
- Первый бросок — через `reactionMs` после старта (± шаг), на 10 сидах.
- Цель: в чистом поле одиночный предмет и плотная тройка на равном расстоянии от моряка, ещё один предмет — за `range + 10`. Бросок уходит к тройке.
- Цели нет — броска нет: предметы убираются перед каждым шагом дольше `reactionMs`.
- Удержание включается через `pullDelayMs` после падения (± 2 шага) и выключается, когда сеть вернулась.
- `pause()` на окне 2-го уровня берёт «Плот», `ms` — в `windowMs`. Стройка — клетка (0, −1): у соседей центра (0, −1) и (1, 0) счёт по 1, при равенстве — первая из `candidates()`; `ms` — в `buildMs`.
- Без «Плота» в окне — первая карточка по `CARD_ORDER`.
- Краб `debugSpawnEnemy(100, 0)`: бросок копья через `crabNoticeMs` (± шаг); краб утонул — слот снова сеть.
- `runSim` — один сид дважды даёт равные результаты. До 2-го уровня окон нет, поэтому время 2-го уровня по часам равно игровому. С окнами часы идут дальше игры.
- `median`, `quantile`, `gate` на маленьких выборках, в том числе с `Infinity`.
