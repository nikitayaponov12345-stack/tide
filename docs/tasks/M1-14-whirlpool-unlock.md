# M1-14 — воронка за рекламу

**Цель.** Из GDD («Монетизация» и «Прогрессия»): воронка открывается один раз на всю кампанию просмотром рекламы — кнопкой «Открыть за рекламу» на её карточке, пока она не открыта; где реклама за награду недоступна, воронка открыта сразу. Заодно — замечание из отчёта M1-12: во время рекламы не открывается пауза, а реклама из окна выбора не шлёт площадке лишних сигналов.

Как понято (толкование Claude, Никита может поправить):
- закрыта воронка, пока у площадки есть реклама за награду (`rewarded`) и в кампании её ещё не открывали. Закрытая карточка видна в окне затемнённой, причина — «Открывается за рекламу», под ней — кнопка «Открыть за рекламу». У оригинала так же: «Разблокировать» на карточке пылесоса;
- реклама досмотрена — воронка открыта навсегда: флаг `campaign.whirlpoolUnlocked` в записи (поле там есть с M1-01). В открытом окне карточка тут же становится доступной, порядок карточек не меняется; нет свободной клетки — она затемнена с обычной причиной «Требуется свободный плот»;
- реклама не досмотрена — ничего не меняется, кнопка остаётся;
- «Стереть прогресс» и `?new=1` стирают и флаг кампании — как вся запись;
- какие постройки открываются за рекламу, говорит колонка `ad_unlock` в `buildings.csv`. Флаг кампании один, поэтому `ad_unlock` = 1 допустим только у воронки — это проверка таблиц;
- окно выбора и так ставит игру на паузу, поэтому реклама из окна сигналов площадке не шлёт. Кнопка буста по-прежнему шлёт «игра остановлена» и «игра идёт». Пока идёт реклама (`ad`), пауза не открывается: так площадка не получит «игра остановлена» дважды (замечание из отчёта M1-12);
- бот `npm run sim` открывает воронку при первом показе её карточки, как живой игрок на ПК; реклама по часам — та же, что у буста (`adMs`), и тоже входит в перерыв межстраничной.

**Что изменится в игре.**
- В окне 6-го уровня карточка «Воронка» затемнена: «Открывается за рекламу», под ней (на телефоне — под стопкой карточек) — оранжевая кнопка «Открыть за рекламу». Нажатие — «реклама» заглушки (мгновенно), и карточку сразу можно взять.
- Открытая воронка остаётся открытой после перезагрузки.
- С `?rewarded=0` воронка открыта сразу, кнопки нет.
- Во время рекламы буста не открывается пауза.
- Версия — 0.0.21: в `main.ts`, `package.json` и в двух полях `version` в `package-lock.json`.

## 2. Колода — `src/core/deck.ts`

- `DeckContext.adLocked?: boolean` — постройки с `ad_unlock` = 1 закрыты до просмотра рекламы; нет поля — не закрыты. Поле необязательное: тесты колоды со своим `ctx` не меняются.
- `AD_LOCKED = 'ui.ad_locked'` (экспорт, рядом с `NEED_FREE_CELL`).
- `Deck` в конструкторе собирает множество построек с `ad_unlock` = 1 из `data.buildings` (закрытое поле, с комментарием).
- `availability`: постройка, `adLocked` истинно и она в этом множестве — `{ available: false, reason: AD_LOCKED }`. Эта проверка — первой, до проверки свободной клетки.
- `refresh(cards, ctx): OfferCard[]` — доступность тех же карточек заново, порядок прежний (для открытого окна).

## 3. Ядро — `game.ts`, `game-cards.ts`, `save.ts`

- `GameConfig.whirlpoolUnlocked?: boolean` — воронку уже открыли в кампании; нет поля — нет. Объявление `GameConfig` — одной строкой, как сейчас, комментарий над ней — про оба необязательных поля (`rewarded` и `whirlpoolUnlocked`).
- Поля `Game`:
  - `readonly rewarded` = `cfg.rewarded ?? true`, и `BoostOffer` получает его же;
  - `whirlpoolUnlocked` = `cfg.whirlpoolUnlocked ?? false`, комментарий — «Воронка открыта на всю кампанию (M1-14). В снимок не входит: это запись кампании».
- `setMenu(on)`: при `on` и идущей рекламе (`ad`) — ничего; комментарий — «во время рекламы не открывается».
- В `game-cards.ts`:
  - `deckContext` — ещё `adLocked: g.rewarded && !g.whirlpoolUnlocked`;
  - `unlockWhirlpool(g)` (экспорт): нет рекламы за награду или уже открыта — `false`; иначе `g.whirlpoolUnlocked = true`, у открытого окна `g.window.cards = g.deck.refresh(g.window.cards, deckContext(g))` (новый массив, окно — тот же объект), `true`;
  - `debugLevelUp(g)` (экспорт) — тело нынешнего `Game.debugLevelUp` переезжает сюда.
- В `game.ts` — методы-обёртки по одной строке: `debugLevelUp()` зовёт `debugLevelUp(this)`, новый `unlockWhirlpool()` — `unlockWhirlpool(this)`. Так `game.ts` остаётся меньше 400 строк (правило 4): у прототипа после правки 386 строк (было 380), у тебя — около 397. Не хватает — комментарии новых полей по одной строке.
- `makeSave`: `campaign.whirlpoolUnlocked` — `game.whirlpoolUnlocked`; комментарий поля `campaign` в `SaveFile` — «Пройденные локации — с M2; открытая за рекламу воронка — с M1-14».

## 4. Сигналы — `control.ts`

`Control.rewarded(show)`: сигналы шлются, только если игра шла:
```ts
const stop = this.playing && this.stopper() === null;
if (stop) this.platform.gameplayStop();
// … await show(), ошибка — «не досмотрена»
if (stop && this.stopper() === null) this.platform.gameplayStart();
```
В комментарии метода — «Игра уже стоит (окно выбора, пауза — M1-14: воронка из окна) — сигналов нет».
