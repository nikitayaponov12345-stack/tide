# Задачи

Как запускать: в PowerShell `cd C:\games\tide`, затем `claude`; в Claude Code — «Выполни задачу docs/tasks/<файл>.md. Перед началом прочитай CLAUDE.md.»

После задачи Claude Code ставит в строке статуса «сделано ДД.ММ» и пишет отчёт. Приёмку по коду делает Claude в чате проекта «игры», коммит и push — Никита.

Порядок пачки 1: S1-01 → M0-01 → M0-02 → M0-03 (каждая следующая опирается на предыдущую; следующую запускать, когда в строке предыдущей стоит «сделано»). Пачка 2: M0-04. Пачка 3: M0-05 → M0-06 (решения Никиты 09.10). Пачка 4: M0-07 → M0-08. Пачка 5: M0-09 → M0-10. Пачка 6: M1-01 → M1-02 — первые задачи M1. Пачка 8: M1-03 → M1-04 (пачка 7 — без задач: приёмка и настройка e2e). Пачка 9: M1-05 → M1-06. Пачка 10: M1-07 → M1-08. Пачка 11: M1-09. Пачка 12: M1-10 — темп как у оригинала (решение Никиты 10.10). Пачка 13: M1-11. Пачка 14: M1-12.
