# M1-20 — обучение без текста, часть 2: первый краб, ремонт, визит

**Цель.** Продолжение M1-19 по GDD («Интерфейс», «Обучение без текста»): «первый враг (пауза: стрелка на слот копья, потом на врага — до первого попадания), событие, визит босса, ремонт». У оригинала то же: «игра стоит на паузе, пока не выбрано копьё, и пауза повторяется до первого попадания копьём».

Как понято (толкование Claude, Никита может поправить):
- **первый краб.** Пока копьё ни разу не попало, а краб подошёл ближе дальности броска копья к моряку, мир стоит: краб, течение, сеть и таймеры не двигаются. Команды при этом работают. Рука сначала на слоте «Копьё», а когда копьё выбрано и лежит у моряка — на ближайшем крабе. Бросок — мир идёт, пока копьё летит. Промах — копьё вернулось, мир снова стоит. Попал — пауз больше нет. Это не пауза игры: окно паузы, сигналы площадке и «игра остановлена» не меняются;
- шаг краба важнее тяги: если сеть лежит, а краб уже рядом — рука на слоте копья;
- **ремонт.** Клетка повреждена, а ремонта ещё не было — рука на молотке. В ремонте — на самой разбитой клетке, до первого нажатия. Мир не стоит;
- **визит.** На первом визите шхуны, пока по ней ни одного удара, — рука на середине корпуса: бей копьём, будут сундуки. Мир не стоит;
- **шторм** — без руки: в шторм делать ничего особого не нужно, его видно по тёмной воде, а крабы и так зовут к копью;
- выключить обучение можно адресом `?tutorial=0` (для тестов, где краб нужен без паузы первого краба). Обычный игрок адреса не видит;
- бот и `sim` обучения не видят: в `GameConfig` оно выключено по умолчанию.

**Что изменится в игре.**
- У первого краба игра замирает, рука показывает на «Копьё», потом на краба. После первого попадания — как раньше.
- Первый ремонт: рука на молотке, потом на клетке. Первый визит шхуны: рука на шхуне.
- Версия — 0.0.27: в `main.ts`, `package.json` и в двух полях `version` в `package-lock.json`.

## 1. Ядро — `tutorial.ts`, `game.ts`

**`src/core/tutorial.ts`:**
- тип шага:
  ```ts
  /**
   * Шаг обучения, который показывает рука: бросок сети, тяга, карточка в окне, клетка в стройке (M1-19); слот копья и
   * краб — у первого краба, молоток и клетка — у первого ремонта, шхуна — на первом визите (M1-20).
   */
  export type TutorialStep = 'throw' | 'pull' | 'card' | 'cell' | 'spear_slot' | 'spear_aim' | 'repair' | 'repair_cell' | 'visit';
  ```
- после `RAFT_CARD`:
  ```ts
  /** Шаги, на которых мир стоит, пока игрок не сделает показанное (первый краб, как у оригинала). */
  const HOLD: readonly TutorialStep[] = ['spear_slot', 'spear_aim'];
  ```
- в комментарий класса — абзац: «Первый краб (M1-20): пока ни одного попадания копья, краб в круге дальности моряка — мир стоит, пока не выбран слот копья, и снова, пока копьё у моряка (holds), — до первого попадания, как у оригинала»;
- `step` целиком:
  ```ts
  /**
   * Шаг сейчас; null — руки нет. Окно выбора — «карточка», пока ни одной не взято; стройка «Плота» — «клетка», пока
   * клетка одна; ремонт — «клетка ремонта», пока ни одного нажатия; иначе на паузе руки нет. Первый краб в круге
   * дальности, пока ни одного попадания копья, — «слот копья», а с копьём у моряка — «краб». Ни одного броска —
   * «бросок», когда сеть у моряка и выбрана; сеть ни разу не тянули — «тяга», когда она лежит на воде. Клетка
   * повреждена, ремонта ещё не было — «молоток». Первый визит шхуны, пока по ней ни одного удара, — «шхуна».
   */
  step(g: Game): TutorialStep | null {
    if (!this.enabled) return null;
    if (g.window) return g.deck.takenTotal() === 0 ? 'card' : null;
    if (g.build) return g.build.card === RAFT_CARD && g.raft.cells.length < 2 ? 'cell' : null;
    if (g.repair) return g.stats.repairTaps === 0 ? 'repair_cell' : null;
    if (g.paused) return null;
    if (g.stats.spearHits === 0 && this.crabInRange(g)) {
      if (g.weapon === 'net') return 'spear_slot';
      if (g.spear.state === 'ready') return 'spear_aim';
    }
    if (g.stats.throws === 0) return g.weapon === 'net' && g.net.state === 'ready' ? 'throw' : null;
    if (!this.pulled && g.net.state === 'lying') return 'pull';
    if (g.stats.repairTaps === 0 && g.raft.damaged()) return 'repair';
    if (g.boss.visiting && g.boss.visits === 0 && g.stats.bossDamage === 0) return 'visit';
    return null;
  }

  /** Мир стоит: шаг первого краба (слот копья или краб, M1-20). */
  holds(g: Game): boolean {
    const s = this.step(g);
    return s !== null && HOLD.includes(s);
  }

  /** Мелкий враг ближе дальности броска копья к моряку. */
  private crabInRange(g: Game): boolean {
    const s = g.sailor;
    return g.spearOwned && g.enemies.list.some((e) => Math.hypot(e.x - s.x, e.y - s.y) <= g.spear.range);
  }
  ```
  `boss.visits` растёт в конце визита, поэтому «первый визит» — `visiting && visits === 0`. Копьё летит или возвращается — мир идёт (иначе копьё не долетело бы).

**`src/core/game.ts`** — первая строка `step`:
```ts
// Первый краб (M1-20): мир стоит, пока игрок не выберет копьё и не попадёт им; команды при этом работают.

```
