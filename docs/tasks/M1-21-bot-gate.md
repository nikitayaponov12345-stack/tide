# M1-21 — бот чинит плот, ворота M1 в отчёте прогона

**Цель.** Ворота M1 из GDD («План», строка M1) и ROADMAP: «Лагуна за 20–25 мин по часам у бота; ни одного тупика за 10 прогонов бота». Бот учится ремонту, как живой игрок, а `npm run sim` считает ворота M1 и падает, если они не пройдены. Третье условие ворот — «Никита доигрывает Лагуну после перерыва с того же места» — проверяет Никита руками.

Как понято (толкование Claude, Никита может поправить):
- бот чинит, когда у какой-нибудь клетки прочность 50 и ниже (половина). Молоток он замечает так же, как краба, — за 0,5–1 с игрового времени. В ремонте нажимает по самой разбитой клетке, пока прочность у всех не станет полной; одно нажатие — 0,3–0,5 с по часам. Числа — толкование Claude: на записях ремонт короткий (13 с за 828 с игры на ПК);
- краб в круге дальности важнее ремонта: сначала копьё;
- ворота M1 — по первым 10 прогонам кривой (сиды 1–10): все 10 дошли до «Локация пройдена», медиана по часам — 20–25 мин, тупиков нет. Тупик — прогон, который не победил в финальном бою за 40 минут игры (предел прогона);
- обучение (M1-19, M1-20) бот не проходит: в `sim` оно выключено, а время обучения у живого игрока — секунды.

**Что изменится в игре.** Ничего: меняются только бот и отчёт `npm run sim`. Версия не меняется.

  ```ts
  repairBelowHp: 50,
  repairNoticeMs: [500, 1000],
  repairTapMs: [300, 500],
  ```
- Поле `private repairAt: number | null = null;`.
- `update` — после блока краба, перед шагами к шхуне:
  ```ts
  // Клетка разбита наполовину и сильнее — через время реакции молоток (M1-21); ремонт — пауза, нажатия — в pause().
  if (!g.raft.cells.some((c) => c.hp <= p.repairBelowHp)) {
    this.repairAt = null;
  } else if (this.repairAt === null) {
    this.repairAt = now + this.span(p.repairNoticeMs);
  } else if (now + TIME_EPS >= this.repairAt) {
    this.repairAt = null;
    this.release();
    if (g.setRepair(true)) return;
  }
  ```
  Центральная клетка неуязвима, её прочность всегда полная.
- `pause` — после сбросов `throwAt`, `pullAt` и `walkAt`, перед `if (g.cleared)` (комментарий метода: «Окно, стройка, ремонт (M1-21), реклама за награду или „Локация пройдена“…»):
  ```ts
  if (g.repair) {
    // Нажатия по самой разбитой клетке, пока прочность у всех полная: тогда ремонт закрывается сам.
    let ms = 0;
    while (g.repair) {
      let worst = g.raft.cells[0]!;
      for (const c of g.raft.cells) if (c.hp < worst.hp) worst = c;
      if (!g.repairCell(worst.gx, worst.gy)) {
        g.setRepair(false);
        break;
      }
      ms += this.span(this.params.repairTapMs);
    }
    return { ms, card: null };
  }
  ```
  Ремонт — пауза мира, поэтому прогон уже зовёт `pause()`, а время нажатий идёт по часам.

    ```ts
     * Ворота M1 (ROADMAP, GDD «План», M1): первые runs прогонов кривой проходят Лагуну («Локация пройдена»), медиана по
     * часам — в wallMs, тупиков нет. Тупик — прогон, не дошедший до победы в финальном бою за maxGameMs игры.
     */
    export const GATE_M1 = { runs: 10, wallMs: [20 * 60_000, 25 * 60_000] } as const;
    ```
  - перед `fightSection`:
    ```ts
    /** Ворота M1 по первым GATE_M1.runs прогонам кривой (M1-21): пройдены ли и строка отчёта. */
    export function gateM1(curve: readonly SimResult[]): { passed: boolean; lines: string[] } {
      const runs = curve.slice(0, GATE_M1.runs);
      const wall = runs.map((r) => r.clearedWallMs).filter((x): x is number => x !== null);
      const stuck = runs.length - wall.length;
      const [lo, hi] = GATE_M1.wallMs;
      const med = wall.length > 0 ? median(wall) : NaN;
      const passed = runs.length === GATE_M1.runs && stuck === 0 && med + 1e-9 >= lo && med <= hi + 1e-9;
      const range = wall.length > 0 ? ` (${min(Math.min(...wall))} – ${min(Math.max(...wall))})` : '';
      const lines = [
        '',
        `**Ворота M1** (Лагуна целиком: ${GATE_M1.runs} прогонов, медиана «Локация пройдена» по часам ${num(lo / 60_000, 0)}–${num(hi / 60_000, 0)} мин, ` +
          `тупиков нет): ${passed ? 'пройдены' : 'НЕ пройдены'}. Прошли ${wall.length} из ${runs.length}, медиана ${wall.length > 0 ? min(med) : '—'}${range}, тупиков — ${stuck}.`,
      ];
      return { passed, lines };
    }
    ```
  - в `toMarkdown` строки ворот M1 — сразу после абзаца ворот M0 (`...gateM1(curve).lines`), до «## Кривая»;
  - в таблице «Прогоны» последняя колонка «Ремонт: раз / нажатий» (`${r.repairs} / ${r.repairTaps}`) и ещё одна `| --- |`.
- `sim/tempo.sim.ts`: импорт `gateM1`, название теста — «темп бота „человек“: ворота M0, кривая уровней и ворота M1», в конце — `expect(gateM1(curve).passed).toBe(true);` с комментарием «Ворота M1 (M1-21): Лагуна целиком у 10 прогонов, по часам 20–25 мин, без тупиков».
