# S0-01 — каркас проекта (этап 0)

**Цель.** В `C:\games\tide` появляется рабочий пустой проект игры: установка зависимостей, тесты, сборка с отчётом о размере и смоук в браузере в двух раскладках. Правил игры ещё нет — на экране заглушка: вода, база из пяти клеток в центре и плывущие кружки.

**Что уже готово.** Код каркаса написан и проверен Cowork 08.10.2026 в песочнице (Linux, Node 22.22, npm 11.6): 15 тестов Vitest зелёные; сборка — 0,49 МБ, сжато 0,14 МБ; смоук Playwright — 2 из 2, снимки обеих раскладок правильные. Твоя задача — перенести его в репозиторий, установить зависимости на Windows и убедиться, что всё зелёное. Код не переписывать и не «улучшать».

## Шаги
1. Проверь версии: `node -v` — нужен 22.12 или новее; `npm -v` — нужен 11 или новее. Если npm 10 — обнови: `npm install -g npm@11` (npm 10 падает на установке этого набора с ошибкой «Cannot read properties of null (reading 'edgesOut')»).
2. Текущая папка — `C:\games\tide` (в ней уже сделан `git init`). Скопируй сюда всё содержимое `C:\games\sea catcher\stage0\tide\` с сохранением структуры, включая `.gitignore`:
   `Copy-Item -Path "C:\games\sea catcher\stage0\tide\*" -Destination . -Recurse -Force`
   Проверь, что на месте `package.json`, `CLAUDE.md`, `src\main.ts`, `tests\unit\world.test.ts`, `tests\e2e\smoke.spec.ts`, `docs\tasks\S0-01-scaffold.md`, `.gitignore`.
3. `npm install` — версии прямых зависимостей закреплены в `package.json` (pixi.js 8.21.0, vite 8.3.1, vitest 5.0.1, typescript 6.0.3, @playwright/test 1.63.0). Файл `package-lock.json` создастся здесь, на Windows; его не удалять.
4. `npx playwright install chromium` — браузер для смоука.
5. `npm run check`. Ожидается:
   - Vitest: `Test Files 4 passed (4)`, `Tests 15 passed (15)`;
   - сборка: строки отчёта о размере и итог около «итого: 0.49 МБ, сжато 0.14 МБ (бюджет 3 МБ)»;
   - Playwright: `2 passed` (проекты `desktop` 1280×720 и `phone` 412×915);
   - снимки `build\shots\s0_desktop.png` и `build\shots\s0_phone.png`.
6. Открой оба снимка и проверь глазами: синяя вода, в центре крест из пяти коричневых клеток, светлые кружки у края, слева вверху строка «Прилив 0.0.1 · landscape» (на телефоне — «portrait») с числом кадров и предметов. На снимке телефона поле вписано по ширине, сверху и снизу тёмные полосы — так и должно быть.
7. В `docs\tasks\README.md` замени статус S0-01 «поставлена 08.10» на «сделано ДД.ММ» (сегодняшняя дата).
8. Не коммить и не пушь — это делает Никита.

## Если что-то не так
- Можно чинить окружение: версию npm, установку браузера, права на папку. Правила, тесты и код заглушки под ошибку не менять.
- Если без правки файла не обойтись — сделай минимальную правку и назови в отчёте файл, строку и причину.
- Если упал смоук — приложи текст ошибки из вывода Playwright и папку `test-results\`.
